# SignOffAI Investor One-Pager

## 1. 一句话定位

SignOffAI 是一个面向数字芯片功能验证与签核的企业级平台，帮助验证团队将“手工式验证+签核”变成“可复现、可审计、可治理”的工程流程。

## 2. 目标问题

当前芯片验证领域存在三大痛点：

- 验证流程碎片化：验证计划、仿真回归、覆盖率分析、调试和签核之间缺乏统一闭环。
- 签核难可审计：工程师依赖经验判断，缺少完整的决策证据包和可追溯审计链。
- 企业级落地难：现有 AI 工具只能生成代码，无法满足项目隔离、权限控制、审计和复现要求。

## 3. SignOffAI 的解决方案

SignOffAI 提供从规格到签核的端到端验证流程：

- 规格解析与验证计划生成
- UVM 验证环境、测试与断言自动化生成
- 回归与覆盖率执行与结果收集
- 调试诊断与问题定位
- 签核报告与证据包自动输出
- 项目隔离、RBAC、审计日志、审批流

## 4. 核心差异化

### 可复现验证证据链
每个阶段产出结构化 artifact、日志、数据库记录和报告，支持“同一输入、同一流程、同一结果”的复现能力。

### 企业级签核交付
不仅输出代码和测试，而是交付“签核证据包”——包含验证计划、回归结果、覆盖率分析、审计日志和签核决定依据。

### 治理与审计能力
内置项目边界、访问控制、审计记录与审批流，为半导体企业提供可管理、可合规的验证平台基础设施。

## 5. 目标客户

- 芯片设计公司验证团队
- ASIC/FPGA IP 厂商和验证外包公司
- EDA 厂商与 IDM 研发验证部门

## 6. 市场机会

### 市场规模估算

- TAM：50–100 亿美元（全球 EDA 与验证自动化市场）
- SAM：5–20 亿美元（企业级验证与签核平台）
- SOM：0.5–2,000 万美元（3–5 年内的可获取市场，早期目标为 0.1%–1% 的客户获取率）

## 7. 商业模式

- 企业许可证/年度订阅
- POC 与付费试点
- 专业服务与集成服务
- 战略合作与行业解决方案

## 8. 现阶段优势与可行性

### 当前能力

- 支持 Markdown 规格输入
- 自动生成验证流水线产物：UVM、测试、断言、报告
- 支持 CLI 与 Web API
- 提供审计与数据持久化（SQLite）
- 可运行“quick_check”快速验证和“full_verification”完整验证流程

### 需要补齐的关键项
