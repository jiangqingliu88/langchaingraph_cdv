# SignOffAI：IC 验证的 AI 签核平台

## 一、问题（The Problem）

IC 验证是芯片设计中最耗时、成本最高的环节，占项目总周期 50%–70%。当前行业痛点：

- **验证流程高度非标准化**：每个项目重复构建验证环境，回归、覆盖率、调试、签核之间数据断裂
- **签核决策缺乏系统证据**：依赖个人经验和口头沟通，无法追溯和审计
- **通用 AI 工具无法落地**：Claude/Copilot/Cursor 无法集成真实 EDA 工具链，缺乏安全、审计、治理能力

## 二、解决方案（The Solution）

**SignOffAI** 是一个面向 IC 验证的可复现 AI 签核平台。它把验证团队的核心工作流（规格分析 → UVM 生成 → 测试生成 → 回归 → 覆盖率分析 → 签核）变为 **可编程、可治理、可审计的工程系统**。

核心能力：

- **可复现**：任意 Agent 动作可一键复现（`vagent dump`）
- **可审计**：每步输出 artifact manifest（hash + 输入 + 输出 + 日志）
- **可治理**：项目隔离、RBAC、Token 预算、人工审批
- **可交付**：最终产出为“签核证据包”，含所有证据、日志、决策依据

## 三、差异化壁垒（Moat）

| 能力 | SignOffAI | 通用 AI 工具 |
|------|-----------|-------------|
| 集成 VCS/Questa/Verdi | ✅ | ❌ |
| 可复现的 artifact | ✅ | ❌ |
| 签核证据包生成 | ✅ | ❌ |
| 企业级治理（审计/隔离/审批） | ✅ | ❌ |
| IC 验证领域语义 | ✅ | ❌ |

## 四、市场机会（Market Opportunity）

- **目标市场**：全球 IC 验证工具市场（2025 年约 80 亿美元，年增 10%+）
- **目标客户**：芯片设计公司（SoC/IP/ASIC）、EDA 工具厂商、验证服务商
- **核心用户**：验证工程师（10 万人+）、验证经理、企业 IT 安全团队

## 五、产品路线图（Roadmap）

| 阶段 | 时间 | 关键交付 |
|------|------|----------|
| Phase 1 | 2026 Q3 | 可复现 Tool 链 + `vagent dump` |
| Phase 2 | 2026 Q4 | 证据驱动平台 + 签核证据包 |
| Phase 3 | 2027 Q1 | 企业级治理（隔离/审计/审批） |
| Phase 4 | 2027 Q2 | AI 辅助签核决策（风险评分/gap 分析） |

## 六、关键指标（KPIs）

- 回归时间缩短 ≥ 40%
- 签核周期缩短 ≥ 30%
- 验证流程可复现率 = 100%
- 证据包生成时间 ≤ 5 分钟

## 七、团队与资源需求（Team & Resources）

- **核心团队**：1 名架构师（IC 验证 + AI 编排），1 名后端工程师（Python/FastAPI），1 名前端工程师（React/WebSocket）
- **技术栈**：Python/FastAPI、LangChain、SQLite/PostgreSQL、React、Docker/K8s
- **所需资源**：初期投资 3–6 个月开发时间，LLM API 预算，EDA 工具许可证（Questa/VCS）

## 八、下一步（Next Steps）

1. 完成 Phase 1 MVP（可复现 Tool 链 + `vagent dump`）

3. 与 2–3 家 IC 设计公司建立试点合作
4. 基于反馈迭代 Phase 2（证据驱动平台）
5. 启动天使轮 / 产业投资对接
