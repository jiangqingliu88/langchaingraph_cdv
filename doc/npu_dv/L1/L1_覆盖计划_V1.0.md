## 1. 覆盖原则

1. **关键行为穷举**：地址、长度、对齐、依赖、状态机、错误类型必须全命中。
2. **非法仓零容忍**：`illegal_bins` 命中即失败，不参与分母美化。
3. **代码覆盖硬指标**：Line / Cond / FSM ≥95%；缺失指标必须显式说明。
4. **形式证明补位**：无法穷举的性质用 Formal 证明，并记录 assume。
5. **证据可追溯**：每个覆盖项对应功能覆盖报告 / vcover / 断言 / 证明。

## 11. 覆盖闭合公式

```text
required    = 计划仓数 − ignore
waived      = 已批准豁免命中的仓
denominator = required − waived
coverage    = hit / denominator
```

- `ignore`、`waived` 分开审计；
- `NA` 不是 pass；
- 代码覆盖缺失指标写 `absent`，不折算为 0% 或 100%。

## 13. 覆盖签核条件

1. 关键功能仓 100% 命中，非法仓 0。
2. 代码覆盖 Line/Cond/FSM ≥95%，或正式 waiver。
3. 所有豁免有 owner / approver / reason / expires。
4. 覆盖报告与 RTL 版本、模型版本绑定。
5. 覆盖缺口全部有结论（补激励 / 豁免 / 设计确认）。
