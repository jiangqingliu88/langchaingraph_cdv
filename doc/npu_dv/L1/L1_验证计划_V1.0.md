---

## 1. 目标

1. 对每个 L1 IP 做功能穷举、接口协议检查和代码覆盖闭合。
2. 为 L2/L3 提供可复用的 IP 级证据（覆盖 + 断言 + 代码覆盖）。
3. 每个 IP 达到本层签核条件后，才允许向 L2 汇聚。

---

## 2. 验证对象与边界

| IP | 验证边界 | 环境 | 形式验证重点 |
|---|---|---|---|
| **glsu** | 全局搬运：地址生成、长度/对齐、依赖、多 Core 仲裁、状态机、错误响应 | UVM 模块级 | 仲裁无饿死、依赖顺序 |
| **llsu** | 核内搬运：格式转换、地址重排、Bank→执行口、乒乓缓冲 | UVM 模块级 | 双缓冲互斥、格式映射 |
| **mpu** | 权限/安全隔离：Region 配置、命中规则、越权拦截、错误上报 | UVM 模块级 + Formal | 无越权通路 |
| **vpu** | 向量 ISA：Opcode、VLEN、掩码、精度、数值边界、依赖 | UVM 模块级 + Formal | 指令语义等价 |
| **niu** | 片外接口：协议握手、Descriptor、地址检查、多 stream、中断/错误 | UVM 模块级 | 协议合规、错误透传 |
| **cmdsched** | 命令调度：队列、任务类型、资源分配、依赖链、多核派发、抢占 | UVM 模块级 | 调度无死锁、依赖保持 |
| **inst_disp** | 指令派发：路由、依赖检查、发射宽度、互锁、Flush、打包 | UVM 模块级 | 互锁/Flush 正确性 |
| **noc** | 互联：拓扑连通、包协议、并发、多播、仲裁、错误透传 | UVM 模块级 / 子系统 | 无死锁、顺序保持 |
| **npu_core** | 单核：指令执行、流水、本地存储、异常 | UVM 模块级 | 流水/异常语义 |

**不在 L1 范围**：多核并发、跨 Cluster 搬运、端到端模型推理（归 L2/L3）。

## 3. 验证项分解

| 类别 | L1 验证内容 | 证据 |
|---|---|---|
| 功能 | 每个 IP 的覆盖项见 `L1_覆盖计划_V1.0.md` | 功能覆盖报告 |
| 接口协议 | 握手、乱序、背压、错误响应 | 协议断言 + 覆盖率 |
| 数据通路 | 地址/数据/格式/重排正确性 | Scoreboard 比对 |
| 控制通路 | 状态机、互锁、仲裁、Flush | SVA / Formal |
| 代码覆盖 | Line / Cond / FSM / Branch | vcover 报告 |
| 非功能 | 复位、低功耗挂起恢复、安全隔离、错误注入 | 专项用例 |

## 4. 回归分层

| 层级 | 内容 | 入口 | 退出 |
|---|---|---|---|
| L1-Smoke | 复位、基本通路、协议握手 | 编译通过 | 冒烟用例全过 |
| L1-Func | 各 IP 功能覆盖项 | Smoke 通过 | 关键 bin 全命中 |
| L1-Corner | 边界、非法、错误注入、低功耗 | Func 通过 | 边界仓全命中，非法仓 0 |
| L1-Formal | 仲裁、互锁、无死锁、协议 | RTL 稳定 | 证明通过或明确 assume |
| L1-Code | 代码覆盖闭合 | 功能稳定 | Line/Cond/FSM ≥95% |

---

## 5. 环境与检查

- UVM 模块级环境：driver / monitor / sequencer / scoreboard。
- 参考模型：优先真实模型；无模型时必须显式标注“不参与签核比对”。
- 断言：协议、互锁、边界、无死锁；空转断言（cover_property 未命中）必须解释。
- 覆盖率：功能 + 代码 + 断言覆盖；探针 `bind` 进 DUT。
- 形式验证：mpu（无越权）、vpu（指令语义）、noc（无死锁）、glsu（仲裁）。

## 8. 风险与应对

| 风险 | 应对 |
|---|---|
| IP 规格不稳定 | 冻结接口与覆盖项后再放量 |
| 参考模型缺失 | 先做协议/结构检查，模型入库后再补比对 |
| 形式环境未就绪 | 先用 SVA + 定向用例覆盖关键性质 |
| 代码覆盖指标缺失 | 补 vcover 指标或正式 waiver |
| IP 间依赖阻塞 | 先做接口 stub，再替换真实 IP |
