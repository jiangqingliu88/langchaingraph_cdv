## 1. 目的与核心原则

### 1.1 目的

解决三大工程痛点：
• 顶层仿真跑不完：L1/L2 分担覆盖，L3 只跑真实场景

• IP 仿真不知道测什么：自顶向下分解，每个 IP 有明确覆盖目标

• 覆盖率加起来不等于顶层通过：证据咬合，层级间覆盖可追溯


### 1.2 核心原则

| 原则 | 含义 |
| --- | --- |
| 顶层保业务 | L3 只关注真实模型端到端推理和真实编译器指令流 |
| 中层保交互 | L2 重点打击多 Core 并发、NoC 拥塞、搬运仲裁、死锁 |
| 底层保细节 | L1 穷举算子 Shape 分支、ISA 行为、搬运地址与数据正确性 |
| 证据咬合 | L3 通过须有 L1/L2 覆盖证据；L3 Fail 须能下沉到 L1/L2 复现 |

## 3. 搬运层次与数据通路

### 3.1 搬运单元三级分层

| 单元 | 层级 | 搬运范围 | 粒度 | 核心职责 |
| --- | --- | --- | --- | --- |
| glsu | Cluster 全局（跨 Core） | 外部 DDR 到 Cluster；Core 间；跨 Bank 大块数据 | 大块（KB~MB 级，长 burst） | 全局搬运调度、多 Core 搬运请求仲裁、地址生成、搬运依赖管理 |
| llsu | npu_core 内部 | Core 内 SRAM Bank 到执行单元；Core 内 Bank 间 | 小块（元素/向量级） | 核内数据排布、格式转换（NHWC到分形）、地址重排、乒乓缓冲管理、执行单元数据源切换 |
| noc | Cluster 互联通路 | 各 Core / glsu / 共享 SRAM / 外部接口之间的数据包路由 | 数据包 | 路由、流控、多播、QoS 仲裁、错误透传（不做搬运调度决策） |

### 3.2 完整数据通路

外部 DDR -> niu（片外接口）-> glsu（全局搬运：DDR 到 Cluster、多 Core 仲裁、搬运依赖、大块地址生成）-> noc（Cluster 互联：路由、多播、流控、背压）-> llsu（核内本地搬运：SRAM Bank 到执行单元、格式转换、乒乓缓冲）-> 执行单元（Tensor/VPU/Scalar）

### 3.3 搬运覆盖的层级归属

| 覆盖项 | 归属层级 | 说明 |
| --- | --- | --- |
| 单块搬运地址/数据正确性 | L1 (glsu / llsu) | 单块读回比对 |
| 搬运地址对齐/跨边界 | L1 (glsu / llsu) | 对齐边界、跨 Bank/跨页 |
| 搬运并发仲裁 | L2 (glsu + noc) | 多 Core 同时发起搬运 |
| 搬运依赖链 | L2 (glsu + cmdsched) | 搬运与计算之间的先后关系 |
| 搬运带宽/拥塞 | L2 (glsu + noc) | 满带宽压力 |
| 搬运与计算重叠 | L2 (glsu + llsu + npu_core) | 双缓冲流水 |
| 端到端搬运正确性 | L3 | 模型数据通路全链路 |

## 5. L1 IP 覆盖职责详述

### 5.1 glsu（Global Load Store Unit）

定位：Cluster 级全局搬运单元，负责跨 Core、跨 Bank、外部 DDR 与 Cluster 之间的大块数据搬移调度。

验证边界：搬运地址生成、搬运依赖管理、多 Core 搬运请求仲裁、搬运状态机、搬运错误响应

| 覆盖项 | 具体内容 | 签核指标 |
| --- | --- | --- |
| 搬运地址空间 | 外部 DDR 全范围、Cluster SRAM 全范围、跨 Bank 边界 | 地址空间 100% |
| 搬运长度/对齐 | 1B到全块；对齐/非对齐起始与结束地址 | 长度x对齐全组合 |
| 搬运依赖 | 先搬后算、搬运间依赖、依赖超时 | 依赖场景 100% |
| 多 Core 仲裁 | 多 Core 同时发起搬运、优先级、防饿死 | 仲裁场景 大于等于90% |
| 搬运状态机 | idle到搬运中到完成/错误到idle；暂停/恢复 | FSM 100% |
| 搬运与计算重叠 | 搬运下一层权重的同时计算当前层 | 双缓冲场景覆盖 |
| 错误响应 | 搬运目标地址非法、传输超时、数据校验失败 | 错误类型 100% |
| 低功耗 | 搬运挂起后恢复，地址与状态不丢 | 场景覆盖 |
| 代码覆盖 | Line/Cond/FSM | 大于等于95% |

### 5.2 llsu（Local Load Store Unit）

定位：npu_core 内部本地搬运单元，负责 Core 内 SRAM Bank 到执行单元的数据搬运与排布。

验证边界：核内地址重排、格式转换、Bank 到执行单元的数据供给、乒乓缓冲

| 覆盖项 | 具体内容 | 签核指标 |
| --- | --- | --- |
| 格式转换 | NHWC到分形/tiling 格式；数据类型转换 | 模式组合 大于等于90% |
| 地址重排 | SRAM 物理地址到执行单元逻辑地址映射 | 映射全验证 |
| Bank 到执行口 | 单 Bank/多 Bank 到 Tensor/VPU 输入口 | 通路覆盖 |
| 乒乓缓冲 | ping/pong 区切换；读写同时 | 切换场景 100% |
| 非对齐小搬运 | 元素级/向量级非对齐搬运 | 边界覆盖 |
| 数据供给连续性 | 执行单元满负荷时搬运不断流 | 连续搬运覆盖 |
| 搬运与计算重叠 | 向执行单元喂当前块同时搬下一块 | 双缓冲场景覆盖 |
| 代码覆盖 | Line/Cond/FSM | 大于等于95% |

## 7. 缺陷下沉与回归闭环流程

### 7.1 流程

L3 Fail -> 隔离缩减（最简模型/指令流/搬运序列）
-> 定位数据通路层：
   数据搬错 -> 定位搬运层：
      跨 Core/外部 DDR 搬错 -> glsu (L1)
      Core 内搬错/格式错 -> llsu (L1)
      路由丢包/错序 -> noc (L1)
   计算精度/算子分支错 -> npu_core (L1)
   向量数值错 -> vpu (L1)
   指令派发乱序 -> inst_disp (L1)
   地址越权 -> mpu (L1)
   外部命令异常 -> niu (L1)
   任务调度死锁 -> cmdsched (L1)
   并发/死锁/拥塞/搬运仲裁 -> L2 Cluster
-> L1/L2 复现 -> RTL 修复
-> 新增定向用例 + 新增 Covergroup Bin
-> L1 -> L2 -> L3 全链条回归

### 7.2 下沉判定速查表

| Fail 现象 | 首选下沉 IP (L1) | 或下沉 L2 | 验证动作 |

| 外部数据搬入内容错 | glsu | — | 定向搬运地址+比对 |
| 跨 Core 搬运丢数据 | glsu | Cluster 搬运并发 | 多核搬运仲裁测试 |
| 权重/特征格式错乱 | llsu | — | 定向格式转换模式 |
| 乒乓缓冲数据串扰 | llsu | — | 乒乓切换场景 |
| 搬运地址越界 | mpu | — | region 权限定向测试 |
| 搬运依赖错乱（算早了） | glsu | cmdsched | 依赖链定向测试 |
| 搬运与计算重叠出错 | llsu | Cluster 双缓冲 | 流水场景测试 |
| NoC 搬运丢包 | noc | Cluster 拥塞 | 长 burst + 背压 |
| 单条指令输出错误 | npu_core 前端 | — | 定向激励 + Formal |

## 8. L2 多 Core Cluster 子系统专项

### 8.1 验证对象边界

包含：N 个 npu_core、glsu 全局搬运、Cluster 级 NoC、共享 SRAM（多 Bank）、跨核同步原语、Cluster 级调度。
不包含：单 Core 内部指令执行细节（归 L1）、片外主机协议细节（归 L1 niu）。

### 8.2 核心验证目标

| 目标域 | 验证什么 | 为什么 L1 做不了 |
| --- | --- | --- |
| 多核并发 | 多 Core 同时执行不同/相同模型，互不干扰 | 单 Core 无并发 |
| 全局搬运仲裁 | glsu 同时服务多 Core 的搬运请求，正确有序 | 单 glsu 环境无多请求 |
| 搬运-计算重叠 | 搬运下一层与计算当前层并行不冲突 | 需要搬运+计算同时跑 |
| 数据一致性 | 一核写共享 SRAM 另一核读，正确有序 | 需要多 Master 同时访问 |
| 同步正确性 | 跨核 Barrier/Event 等待-唤醒时序 | 单核无同步对象 |
| NoC 拥塞 | 多核满负荷时 NoC 不丢包、不饿死 | L1 只验连通不验压力 |
| 死锁/活锁 | 多核互等搬运/资源不形成环路 | 单核无死锁可能 |
| 任务分片 | 大模型拆到多核的分片策略正确性 | 需要真实调度逻辑 |
| 性能瓶颈 | 搬运带宽/NoC/SRAM Bank 瓶颈定位 | 单核看不出系统瓶颈 |

### 8.3 搬运链路专项覆盖

| 搬运场景 | 描述 | 覆盖目标 |
| --- | --- | --- |
| 权重广播 | glsu 一份权重到多 Core（经 NoC 多播） | 多播正确性 |
| 层间数据传递 | Core A 输出到 glsu/NoC 到 Core B 输入 | 跨核搬运正确性 |
| 搬运并发 | 多 Core 同时向 glsu 发起搬运请求 | 仲裁公平性 |
| 搬运依赖链 | 搬运 Layer N+1 权重 依赖 Layer N 完成 | 依赖触发时序 |
| 搬运带宽饱和 | 全 Core 同时发起大块搬运 | 无丢包、延迟可控 |
| 搬运中的计算 | 一核搬运同时另一核计算 | 无资源冲突 |
| 乒乓式双缓冲 | glsu 搬 N+1 到空闲区，Core 算 N 区 | 切换正确性 |
| 搬运错误注入 | glsu 搬运中注入错误 | 错误上报 + 重试 |
