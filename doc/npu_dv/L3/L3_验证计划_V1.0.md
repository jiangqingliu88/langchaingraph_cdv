---

## 1. 目标

1. 验证真实模型端到端推理：编译 → 下发 → 执行 → 结果比对。
2. 验证性能、长稳、DVFS、复位与安全场景。
3. 用 L1/L2 证据支撑 L3 结论；L3 失败必须能下沉复现。

**L3 不做**：IP 内部功能穷举、多核 arbitration 细节（归 L1/L2）。

---

---

## 3. 验证场景

| 类别 | 场景 | 目标 |
|---|---|---|
| 模型端到端 | 多模型、多 batch、多分辨率 | 通过率 100% |
| 三方差分 | RTL vs 模型 vs 参考输出 | 误差在阈值内 |
| 指令流 | 编译器真实输出、边界指令 | 覆盖目标指令流 |
| 性能 | 吞吐 / 延迟 / 带宽 / 利用率 | 达到设计目标 |
| DVFS | 频率/电压切换中推理 | 无错误、无丢数据 |
| 长稳 | 指定时长连续推理 | 无退化 |
| 复位 | 推理中复位、恢复 | 结果正确 |
| 安全 | 安全/非安全并发、越权 | 无越权 |
| 错误注入 | 搬运/NoC/DDR error | 可检测、可恢复 |

---

## 4. 环境与检查

- **UVM Top**：真实模型 + 编译器指令流；Top scoreboard 比对。
- **Emulation / FPGA**：长稳、性能、系统级场景。
- **参考模型**：模型入库并验证；无模型时不能签 READY。
- **三方比对**：RTL 输出 / 模型输出 / 参考输出。
- **性能采集**：吞吐、延迟、带宽、利用率、功耗（若可采）。
- **证据**：L1/L2 签核文档 + 覆盖报告 + 性能报告 + 长稳日志。

## 5. 回归分层

| 层级 | 内容 | 退出条件 |
|---|---|---|
| L3-Smoke | 单模型端到端 | 推理正确 |

| L3-DVFS | 动态频率/电压 | 无错误 |
| L3-Soak | 长稳 | 无退化 |
| L3-Safety | 安全/复位/错误注入 | 场景覆盖 |
| L3-Regression | 全量模型回归 | 无新增失败 |

## 8. 风险与应对

| 风险 | 应对 |
|---|---|
| 模型/编译器版本漂移 | 冻结模型与编译器版本，记录哈希 |
| 参考输出不可得 | 先做模型自比对，再补参考输出 |
| Emulation 资源不足 | 先 UVM Top，再按需上 Emulation |
| 性能受环境干扰 | 固定配置与种子，多次取中位数 |
| L1/L2 证据缺失 | 未闭合前 L3 只能 CONDITIONAL |
