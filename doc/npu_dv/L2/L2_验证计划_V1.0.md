## 1. 目标

1. 验证多 Core 并发、搬运仲裁、NoC 拥塞、死锁与一致性。
2. 验证全局搬运（glsu）与核内搬运（llsu）的流水配合。
3. 为 L3 提供可追溯的子系统证据：交互覆盖 + 性能 + 一致性结论。

---

## 2. 验证对象与边界

| 组成 | 验证内容 | 不在本层 |
|---|---|---|
| **glsu** | 多 Core 搬运请求仲裁、地址生成、依赖管理、跨 Bank 大块搬运 | 单块搬运细节（L1） |
| **Cluster NoC** | 路由、流控、多播、QoS、背压、错误透传 | 单节点协议（L1） |
| **共享 SRAM** | 多 Core 访问冲突、Bank 冲突、一致性 | SRAM 单元（L1） |
| **跨核同步** | Barrier、Mailbox、锁、事件 | 单核内部流水（L1） |
| **npu_core 集成** | 计算与搬运重叠、双缓冲流水 | Core 内部功能（L1） |

**层级边界**：L2 只验证“跨 IP / 跨 Core 的交互”，不重复 L1 的功能穷举。

---

## 3. 验证场景

| 类别 | 场景 | 目标 |
|---|---|---|
| 并发 | 2 / 4 / 全 Core 同时计算 | 并发度覆盖 |
| 搬运仲裁 | 多 Core 同时发起 glsu 搬运 | 优先级、防饿死 |
| 拥塞 | NoC 满带宽、热点、背压 | 拥塞曲线 |
| 死锁 | 环形依赖、资源互等 | 无死锁 |
| 一致性 | 共享 SRAM 读写、跨核可见性 | 一致性 100% |
| 同步 | Barrier 到达/释放、中断穿插 | 同步场景覆盖 |
| 流水 | 计算与搬运双缓冲 | 双缓冲覆盖 |
| 错误 | 搬运错误传播、NoC error 透传 | 错误类型 100% |
| 复位 | 异步复位、部分 Core 复位 | 恢复正确 |
| 低功耗 | 搬运/计算中电源切换 | 场景覆盖 |

## 4. 环境与检查

- **子系统 UVM 环境**：多 Core agent、glsu/NoC 模型、共享 SRAM 模型。
- **Scoreboard**：跨核事务级 expected vs actual；共享内存一致性检查。
- **Monitor**：每 Core、glsu、NoC 端口；时间戳对齐。
- **死锁检测**：超时 + 依赖环检测；失败必须能定位到 IP。
- **性能采集**：带宽、延迟、仲裁等待、NoC 拥塞。
- **资源 checker**：共享资源冲突策略（`EXCLUSIVE` / `ARBITRATED`）。

## 5. 回归分层

| 层级 | 内容 | 退出条件 |
|---|---|---|
| L2-Smoke | 单 Core 通路、基本同步 | 编译 + 冒烟通过 |
| L2-Concurrency | 2/4/全 Core 并发 | 并发场景覆盖 |
| L2-Arbitration | 搬运仲裁、QoS、防饿死 | 仲裁场景 ≥90% |
| L2-Congestion | NoC 满带宽、背压 | 拥塞曲线覆盖 |
| L2-Consistency | 共享 SRAM / 跨核可见性 | 一致性 100% |
| L2-Deadlock | 死锁压力 | 无死锁或可解释 |
| L2-Soak | 长稳 | 指定时长无退化 |

## 8. 风险与应对

| 风险 | 应对 |
|---|---|
| 多核激励难以构造 | 先做 2 Core，再扩到 4/全 Core |
| NoC 模型精度不足 | 用真实 NoC 模型或标注为结构模型，结论降级 |
| 死锁不可复现 | 固定种子 + 依赖注入 + 波形回放 |
| 性能数据受机器影响 | 固定环境与种子，记录版本与配置 |
| 共享 SRAM 模型缺失 | 先做行为模型，明确不作为最终签核依据 |
