# RTL Freeze

> **一句话**：RTL Freeze 不是「设计写完了」，而是**基线定了** ——
> 从这一刻起，验证跑出来的所有结论都只对**这个版本的 RTL** 成立。

本域有两个出档门，这是**设计侧**那张。验证侧那张（签核）判据完全不同：
一个看「RTL 能不能作为基线」，一个看「基线有没有被证明是对的」。

## 触发条件

- 功能开发完成，所有 feature 已实现，没有留在代码里的 stub / TODO
- 计划上的 freeze 里程碑到了
- 验证侧的验证计划已评审，TB 能编译当前 RTL 并跑通冒烟

**三条缺一条都不该 freeze** —— 尤其是第三条：TB 编译不过就 freeze，
等于把集成问题推迟到回归阶段才发现，那时定位成本高一个量级。

## 各阶段与负责人

| 阶段 | 谁做 | 产物 |
|---|---|---|
| 设计自检 | 设计工程师 | lint / CDC / 综合 三份报告 |
| 交叉复核 | 设计负责人 | waiver 清单（每条有理由） |
| 验证确认 | 验证负责人 | 冒烟通过记录 + 验证计划版本 |
| 放行 | 设计负责人 | **freeze 记录**（版本号 / tag / commit hash） |

## 准入 / 准出

| 检查项 | 准入（freeze 前） | 准出（freeze 后） |
|---|---|---|
| **RTL 完成度** | 所有 feature 实现，无 stub | 版本打 tag，hash 记入 freeze 记录 |
| **Lint** | errors = 0；warning 有 waiver | waiver 清单归档，每条有理由与审批人 |
| **CDC / RDC** | 同步器合规，跨域路径无遗漏 | 报告归档；新增跨域路径必须重跑 |
| **可综合性** | 能综合；无 latch 推断、无组合环 | 综合脚本与 SDC 版本一并冻结 |
| **时序初判** | 初版 SDC 下无「明显不可收敛」的路径 | —（正式收敛在综合域，不在这道门） |
| **DFT 就绪** | scan 可插入；`test_mode` 等端口已接 | DFT 脚本随基线冻住 |
| **低功耗**（若有 UPF） | UPF 与 RTL 一致性检查通过 | UPF 版本随 RTL 一起冻结 |
| **文档** | 寄存器手册、接口文档与 RTL 一致 | 文档版本与 RTL 版本对应 |
| **验证侧** | 验证计划已评审；TB 编译通过 | 冒烟测试通过，可开始正式回归 |

> **时序只做初判，不做收敛** —— freeze 时用初版 SDC 粗看有没有明显做不出来的路径。
> 真正的时序收敛是综合域的事（`design/02_综合_时序_PPA/`）。把收敛塞进 freeze 门，
> 门就永远开不了。

## 制品

freeze 记录至少要回答这四个问题，否则这个门等于没走：

| 要回答的问题 | 制品里的字段 |
|---|---|
| 冻的是**哪一个** RTL？ | 版本号 / tag / commit hash |
| 凭什么冻？ | lint、CDC、综合三份报告 + waiver 清单 |
| 谁拍的板？ | 设计负责人签字 + 验证负责人会签 |
| 冻的是**哪一套**约束？ | 综合脚本、SDC、UPF 的版本 |

## 冻住之后

**冻结 = 基线固定，不是开发停止。** 之后的任何 RTL 改动走 **ECO**：

1. 提 ECO，说明改什么、为什么、影响哪些验证结论
2. 重新过本门的**相关项**（改时钟域就重跑 CDC，改逻辑就重跑 lint + 冒烟）
3. 基线**版本号 +1**，不是覆盖原版本

## 坑

| 坑 | 后果 | 正确做法 |
|---|---|---|
| 把 freeze 当「开发结束」 | 冻结后随便改 RTL，验证结论全部作废却没人知道 | 任何改动走 ECO，基线版本 +1 |
| lint waiver 只写「已知问题」 | 后面没人敢碰，也不知道该不该碰 | waiver 写清「为什么可以忽略」+ 审批人 |
| 没有版本标识 | 出了问题复现不了，也说不清验的是哪版 | freeze 记录带 tag / commit hash |
| TB 编译不过就 freeze | 集成问题推迟到回归阶段才暴露 | 冒烟通过是准入项，不是「尽量」 |
| 在 freeze 门里做时序收敛 | 门永远开不了 | 只做初判，收敛归 `design/02_综合_时序_PPA/` |
| 验证计划没评审就 freeze | 回归方向没人确认过，跑完才发现漏了整块功能 | 验证计划评审是准入项 |
