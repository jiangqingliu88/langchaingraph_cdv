# 流程与签核

**位置**：共用域

> **两个出档门**：设计的 **RTL Freeze** 与验证的**签核**。
> 两张门同构 —— 触发条件、准入/准出、制品、谁放行 —— 但判据不同，各写各的卡。



## 边界

**不放**：单点技术怎么做 → `design/` 与 `verify/` 各域；某次项目怎么做的 → `verify/06_项目案例/`。
>
> **本域只管「门」**：谁能放行、放行的判据是什么、产物归档到哪。**判据怎么算出来的**不在本域。

这条比「放什么」更重要 —— 一个知识库烂掉，几乎总是从「什么都往里塞」开始的。
