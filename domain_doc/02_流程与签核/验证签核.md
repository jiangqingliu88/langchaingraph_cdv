# 验证签核

> **一句话**：签核不是「测够了」，是**有证据地说明够到哪、还剩什么、谁认这个账**。

本域有两个出档门，这是**验证侧**那张。设计侧那张（RTL Freeze）签的是**基线**：
「从这一刻起验证结论只对这个 RTL 成立」。这张门签的是**结论**：「这个 RTL 被证明到什么程度」。

**顺序不能反**：RTL 没冻就签核，签的是一个还在动的对象，签完就作废。

## 触发条件

- 覆盖率停止增长（趋势成平台期，不是「这轮没提高」）
- 最终回归零失败
- 种子数达到项目规定值
- 所有未覆盖 bin 已有 waiver 或已覆盖

## 各阶段与负责人

| 阶段 | 谁做 | 产物 |
|---|---|---|
| 覆盖率对账 | DV 工程师 | 缺口清单 + 逐条归因 |
| Waiver 评审 | 验证负责人 | waiver 表（每条有理由 + 审批人） |
| 形式属性确认 | 形式验证工程师 | 全部属性 PROVEN 记录 |
| 交叉复核 | 设计负责人 | 对缺口与 waiver 的会签 |
| 放行 | 验证负责人 | **签核记录**（RTL 基线版本 + 回归批次） |

## 准入 / 准出

| 检查项 | 准入（签核前） | 准出（签核后） |
|---|---|---|
| 功能覆盖率 | Functional = 100% | 报告归档，挂到 RTL 基线版本上 |
| 条件覆盖率 | Condition ≥ 95% | 同上 |
| 翻转覆盖率 | Toggle ≥ 90%（控制逻辑 ≥ 95%） | 同上 |
| 状态机覆盖率 | FSM = 100%（**含转移弧**） | 同上 |
| 断言覆盖率 | Assertion = 100%（每条 SVA 有 pass **和** fail） | 同上 |
| 代码覆盖率 | Code ≥ 95% | 同上 |
| 回归 | 最终回归零失败 | 回归批次号记入签核记录 |
| 覆盖率趋势 | 趋势图显示收敛（非平台期/非跳变） | 趋势图归档 |
| 未覆盖 bin | 全部有 waiver 或已覆盖 | waiver 表归档 |
| 形式验证 | 所有属性 PROVEN | 形式报告归档 |
| 签字 | 验证负责人 + 设计负责人 | 签核记录归档 |

> **「每条 SVA 有 pass 和 fail」这条最容易糊过去**：一条永远不 fail 的断言，
> 可能写错了、可能约束根本触发不了它 —— 它给的是**假信心**，不是证据。
> 断言覆盖率要同时看 pass 和 fail 都出现过。

## Waiver

| Waiver ID | Bin | 理由 | 审批人 | 日期 |
|---|---|---|---|---|
| W-001 | `cg_fifo::bin_dead_code` | 死代码，架构不可达 | 设计负责人 | |
| W-002 | `cg_pwr::bin_unreachable` | 形式验证已证明不可达 | 验证负责人 | |

**阈值**：未覆盖 bin 中 waived 的比例 **≤ 2%**，超过阈值需重新审查。

**为什么要有阈值**：waiver 是唯一能把「没测到」变成「不用测」的机制 ——
没有比例上限，它就会变成「把覆盖率改到 100%」的快捷键（见 `KB-DV-COV-001` 的 `ignore` 滥用）。

**每条 waiver 必须能回答**：为什么这条**不需要**测？答案是
「架构不可达」时要有可达性证据（形式证明），不是「测了很久没测到」。

## 制品

签核记录至少要回答这四个问题，否则这个门等于没走：

| 要回答的问题 | 制品里的字段 |
|---|---|
| 签的是**哪一个** RTL？ | RTL 基线版本号 / commit hash（与 RTL Freeze 同源） |
| 凭什么签？ | 覆盖率报告（六类）+ 趋势图 + 形式报告 |
| 还剩什么没测？ | 缺口清单 + waiver 表（含理由与审批人） |
| 谁拍的板？ | 验证负责人 + 设计负责人签字 |

## 坑

| 坑 | 为什么诱人 | 后果 |
|---|---|---|
| 覆盖率到 100% 就签 | 数字好看 | 100% 可能是 waiver 换来的；没见过 fail 的断言给了假信心 |
| 平台期当收敛 | 「这几轮没动，说明到头了」 | 平台期可能是**激励打不到**，不是覆盖完了 —— 要区分 |
| waiver 无上限 | 「都是确实不可达的」 | 2% 的阈值是这条机制唯一的分界线 |
| 趋势跳变当收敛 | 最后一轮突然涨满 | 多半是加了 `ignore_bins`，不是加激励 |
| 没冻 RTL 就签 | 赶进度 | 签的是移动靶，签完 RTL 一改全部作废 |
| 签核记录不写 RTL 版本 | 「报告里有日期」 | 半年后没人能复现这份签核对应哪版 RTL |
