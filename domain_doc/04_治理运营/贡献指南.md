# 贡献指南

## 加一条知识

1. **先搜，再写。** 在 `01_术语与索引/索引.csv` 里搜关键词。已经有了就**改那张卡**，
   不要新建 —— 两份就会漂移。
2. **判断它属于哪一域。** 对不准就看那个域的 `_index.md` 里的「**不放什么**」。
   判据是「**这条知识主要用来回答哪类问题**」，不是「它提到了什么」。
3. **挑卡型**（[卡片模板.md](卡片模板.md)），按那个卡型的正文骨架写。
   卡型决定结构，别自由发挥。
4. **落文件**：`<域>/<子域>/<域码>-<序号>-<标题>.md`。
5. **更新两个索引**（缺一不可）：
   - 本域 `_index.md` 的「本域条目」表
   - `01_术语与索引/索引.csv`
6. **标状态**：新卡一律 `草稿`。评审过才升 `评审中` / `已验证`。

## 从 `doc/` 往这里搬

`doc/` 是笔记堆，本库是有结构的知识库 —— **搬的时候要按卡片模板重写一遍**。

直接搬文件等于把笔记堆换个地方堆，而且会带来一个更糟的后果：
同一件事在 `doc/` 与本库各有一份，日后改了一处，另一处就成了错的。

搬的判据：**这份笔记里有没有一句话是你自己的判断？**
有 → 值一张卡；没有（纯抄的文档）→ 记个链接到 `references` 就够了。

## 什么样的卡值得写

| 值得 | 不值得 |
|---|---|
| 你踩过的坑，且能说清怎么复现 | 厂商文档里抄一遍的参数表 |
| 你做的取舍，以及当时为什么 | 「XX 很重要」这类正确的废话 |
| 两个易混概念的**区别** | 一个概念的百科式定义 |
| 一段复制粘贴就能用的模板 | 大段示例代码，没有一句说明用在哪 |

## 不该做的事

- **不要复制**别的卡的内容 —— 用 `related` 链接
- **不要自造标签** —— 见 [标签字典.md](标签字典.md)
- **不要绕过评审直接标 `已验证`** —— 状态是别人给的，不是自己给的
