# 验证方法学

**位置**：`verify/` 验证翼

> **怎么做验证**的路线：UVM、形式验证、覆盖率驱动、低功耗/安全/车规。

## 子域

| 子目录 | 放什么 |
|---|---|
| `UVM` | UVM 方法学：组件分层、phase、factory、config_db、sequence |
| `形式验证` | FPV / 等价性 / 属性验证 |
| `覆盖率驱动验证` | CDV：从覆盖目标反推激励 |
| `低功耗_安全_车规` | UPF / ISO 26262 / DO-254 |


## 边界

**不放**：某个组件**具体怎么写** → `verify/03_技术与组件/`；某个工具的开关 → `verify/04_工具与脚本/`。

这条比「放什么」更重要 —— 一个知识库烂掉，几乎总是从「什么都往里塞」开始的。
