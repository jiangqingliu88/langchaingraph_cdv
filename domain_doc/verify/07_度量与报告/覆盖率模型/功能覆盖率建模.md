# 功能覆盖率建模

> **一句话**：Coverpoint 不是凭空想的，是从模块的**功能契约**推导出来的。
> 掌握推导法，拿到任何模块都能列出覆盖点，而不是去套一份别人的模板。

## 适用场景

- 新模块第一次写覆盖模型，不知道覆盖点从哪来
- 评审一份覆盖模型：它是不是只覆盖了「正常路径」
- 覆盖率收敛卡住，要判断**缺的是激励，还是模型本身漏了**

## 不适用

| 你实际想干的事 | 该去哪 |
|---|---|
| 让已有 bin 的命中率上去 | `verify/07_度量与报告/覆盖率收敛/` |
| 定代码 / 断言覆盖率的目标值、waiver 门槛 | `02_流程与签核/` |
| 记录这次项目跑出来的实测覆盖率 | `verify/06_项目案例/` |

**这条比「适用」更值钱**：把「怎么建模」和「怎么收敛」混在一张卡里，
下次换项目时两件事都得重读一遍。

## 一、源头：三类契约

模块的所有覆盖点都能追溯到三类契约之一。**推导不出契约的覆盖点，就是拍脑袋想的**。

| 契约类型 | 含义 | 推导出的覆盖维度 |
|---|---|---|
| **接口契约** | 输入输出信号、协议、时序 | 信号取值、协议状态、握手组合 |
| **功能契约** | 模块应该做什么 | 操作类型、模式、配置 |
| **异常契约** | 什么情况下应报错 / 阻塞 / 恢复 | 错误类型、边界条件、恢复路径 |

**建模的本质 = 把三类契约拆解成可测量的取值空间。**

## 二、九步建模法

前五步覆盖「接口 + 功能 + 异常」，第 6–8 步把维度抬到并发 / 系统 / 非功能，
第 9 步回头验模型自身。**每一步都要留下产物**——没有产物的步骤等于没做。

| 步 | 做什么 | 产物 |
|---|---|---|
| 1 | **列信号**：把输入输出信号全列出来 | 信号清单 |
| 2 | **信号取值**：每信号分正常 / 边界 / 特殊 / 非法四类 | 每信号的取值清单 |
| 3 | **信号组合**：输入×输入、输入×输出、输出×输出 | 有意义的组合对 |
| 4 | **时序序列**：握手序列、状态转移、依赖序列 | 序列清单 |
| 5 | **异常场景**：非法命令、超时、越界、协议违规、背压 | 异常清单 |
| 6 | **并发维度**：多事件同时发生 | 并发场景 |
| 7 | **系统维度**：跨模块、端到端 | 系统场景 |
| 8 | **非功能维度**：性能 / 功耗 / 时序 / 可靠性 / CDC | 非功能覆盖点 |
| 9 | **元维度**：覆盖模型自检（见第四节） | 自检结论 |

### 第 2 步：「取值」到底分哪四类

```systemverilog
cp_opcode: coverpoint op {
  bins normal  = {ADD, SUB};              // 正常值：常规操作范围
  bins boundary = {MAX_OP, MIN_OP};       // 边界值：最大 / 最小 / 临界
  bins special  = {0, NOP};               // 特殊值：0、全 1、保留值
  bins illegal  = {8'hFF};                // 非法值：协议不允许的编码
}
```

**只写正常值的覆盖点，是覆盖模型最常见的失败模式** —— 它测不出错误路径。

### 第 3 步：组合要挑，不是全叉

输入×输入（`op × mode`）、输入×输出（`req × rsp_type`）、输出×输出（`done × error`）。
**组合要挑「架构上有意义」的** —— 全量 cross 的结果是 bin 数上万、涨不上去、也没人看（见第六节）。

### 第 6–8 步：三个常被整段跳过的维度

```systemverilog
// 并发：多事件同时发生
cp_concurrent: coverpoint {portA_req, portB_req} {
  bins both_req = {2'b11};  bins only_a = {2'b10};
  bins only_b   = {2'b01};  bins neither = {2'b00};
}
cp_hazard: coverpoint hazard_type {          // 流水线冒险
  bins raw = {RAW};  bins war = {WAR};  bins waw = {WAW};
}

// 系统：跨模块 / 端到端
cp_e2e_scenario: coverpoint scenario {
  bins dma_to_dram_to_cache = {DMA_DRAM_CACHE};
  bins intr_during_dma      = {INTR_DMA};
}
cp_sys_state: coverpoint {modA_state, modB_state} {
  bins a_idle_b_active = {2'b01};  bins both_active = {2'b11};
}

// 非功能：性能 / 功耗 / 可靠性
cp_latency: coverpoint latency {
  bins min_lat = {1};  bins typical = {[2:8]};
  bins long_lat = {[9:100]};  bins timeout = {TIMEOUT};
}
cp_power: coverpoint power_state {
  bins on = {ON};  bins sleep = {SLEEP};  bins deep = {DEEP_SLEEP};
}
cp_recovery: coverpoint recovery {
  bins auto_recover = {AUTO};  bins need_reset = {RESET};  bins fatal = {FATAL};
}
```

**判据**：一个覆盖点在回归里永远 0%，是模型的洞还是激励的锅？
第 6–8 步漏掉的那几类，答案几乎总是「模型的洞」。

## 三、按模块类型的重点

**同一个九步法，不同模块类型的重点完全不同** —— 抓错重点，模型就白写。

| 模块类型 | 典型模块 | 重点在 |
|---|---|---|
| 状态机密集 | 协议控制器、定时器、电源管理、仲裁 FSM | **转移弧与多周期转移序列**（只有状态不够） |
| 缓冲 / 队列 | FIFO、重排序缓冲、发射队列 | **满时写、空时读、同时读写**（边界行为） |
| 总线 / 接口 | AXI / APB / AHB / PCIe 控制器 | **协议完整性**：全传输类型 × 全响应 × 背压 |
| 调度 / 仲裁 | 仲裁器、指令调度、DMA 调度 | **决策正确性**：什么请求组合下授权给谁、是否公平 |
| 数据通路 | ALU、乘法器、CRC、编解码 | **边界值与标志位**：max / min / 溢出 / 进位 |
| 缓存 / 存储 | Cache、TLB、MMU、SRAM 控制器 | **命中缺失路径、替换策略、一致性状态转移** |
| 流水线 | CPU / DSP / 网络流水线 | **冒险、冲刷、停顿、转发** |
| NoC / 网络 | 片上网络、路由器、交换结构 | **路由正确性、拥塞、死锁避免、QoS** |
| 加密 / 安全 | AES、RSA、SHA、TRNG、安全启动 | **模式、密钥长度、侧信道防护、随机数质量** |
| DMA | DMA 控制器、描述符引擎 | **描述符处理、链式传输、错误恢复** |
| 中断控制器 | GIC、NVIC | **优先级仲裁、嵌套、屏蔽** |
| 时钟 / 复位 | 时钟/复位控制器、CDC 同步器 | **复位序列、时钟域切换、CDC 同步** |

### 附录：各类型覆盖点速查

可直接粘贴起步，**但必须按本模块的契约改**——照抄是本节唯一正确的用法。

```systemverilog
// ── 状态机密集 ──
cp_state: coverpoint current_state {
  bins idle = {IDLE};  bins active = {ACTIVE};  bins error = {ERROR};  bins done = {DONE};
}
cp_transition: coverpoint current_state {
  bins t_idle_active  = (IDLE => ACTIVE);
  bins t_active_wait  = (ACTIVE => WAIT);
  bins t_wait_done    = (WAIT => DONE);
  bins t_active_error = (ACTIVE => ERROR);
}
cp_seq: coverpoint current_state {           // 多周期转移序列
  bins s_idle_active_wait = (IDLE => ACTIVE => WAIT);
}
illegal_bins t_illegal = (IDLE => DONE);     // 非法转移要显式写出来

// ── 缓冲 / 队列 ──
cp_level : coverpoint level { bins empty = {0}; bins low = {[1:3]}; bins full = {DEPTH}; }
cp_op    : coverpoint op    { bins wr = {WRITE}; bins rd = {READ}; bins rst = {RESET}; }
cp_result: coverpoint result{ bins success = {OK}; bins blocked = {BLOCKED}; bins error = {ERROR}; }
X_full_wr: cross cp_level, cp_op, cp_result {          // 关键交叉：满时写 / 空时读
  bins full_write_blocked = binsof(cp_level.full) && binsof(cp_op.wr) && binsof(cp_result.blocked);
  bins empty_read_blocked = binsof(cp_level.empty) && binsof(cp_op.rd) && binsof(cp_result.blocked);
}
cp_simultaneous: coverpoint {wr_en, rd_en} { bins both = {2'b11}; }

// ── 总线 / 接口 ──
cp_trans_type: coverpoint trans_type { bins read = {READ}; bins write = {WRITE}; }
cp_burst_len : coverpoint burst_len  { bins len1 = {1}; bins len4 = {4}; bins len16 = {16}; }
cp_rsp       : coverpoint rsp_type   {
  bins okay = {OKAY}; bins exokay = {EXOKAY}; bins slverr = {SLVERR}; bins decerr = {DECERR};
}
cp_backpressure: coverpoint ready { bins ready_high = {1}; bins ready_low = {0}; }
X_trans_rsp: cross cp_trans_type, cp_rsp {
  bins read_slverr  = binsof(cp_trans_type.read)  && binsof(cp_rsp.slverr);
  bins write_decerr = binsof(cp_trans_type.write) && binsof(cp_rsp.decerr);
}
cp_protocol_violation: coverpoint violation_type {
  bins illegal_burst = {ILLEGAL_BURST}; bins misaligned = {MISALIGNED}; bins timeout = {TIMEOUT};
}

// ── 调度 / 仲裁 ──
cp_req_num : coverpoint req_num  { bins none = {0}; bins one = {1}; bins many = {[3:$]}; }
cp_priority: coverpoint priority { bins low = {LOW}; bins mid = {MID}; bins high = {HIGH}; }
cp_grant   : coverpoint grant    { bins port0 = {0}; bins port3 = {3}; bins none = {NONE}; }
cp_conflict: coverpoint conflict {
  bins no_conflict = {NONE}; bins same_port = {SAME_PORT}; bins same_priority = {SAME_PRIO};
}
X_req_grant    : cross cp_req_num, cp_grant;
X_prio_conflict: cross cp_priority, cp_conflict;

// ── 数据通路 ──
cp_op: coverpoint op { bins add = {ADD}; bins sub = {SUB}; bins xor = {XOR}; }
cp_operand_a: coverpoint a {
  bins zero = {0}; bins one = {1}; bins max = {32'hFFFF_FFFF};
  bins min = {32'h8000_0000}; bins mid = {[2:32'h7FFF_FFFE]};
}
cp_flags: coverpoint flags {
  bins zero_flag = {ZERO}; bins carry_flag = {CARRY};
  bins ovf_flag = {OVERFLOW}; bins neg_flag = {NEG};
}
X_op_operand: cross cp_op, cp_operand_a, cp_operand_b;

// ── 缓存 / 存储 ──
cp_access     : coverpoint access_result { bins hit = {HIT}; bins miss = {MISS}; bins bypass = {BYPASS}; }
cp_access_type: coverpoint access_type   { bins read = {READ}; bins write = {WRITE}; bins fetch = {FETCH}; }
cp_replace    : coverpoint replace_way   { bins way0 = {0}; bins way3 = {3}; }
cp_coherence  : coverpoint coh_state {
  bins modified = {M}; bins exclusive = {E}; bins shared = {S}; bins invalid = {I};
}
cp_coh_trans: coverpoint coh_state { bins m_to_s = (M => S); bins i_to_e = (I => E); }
X_access_result: cross cp_access_type, cp_access;

// ── 流水线 ──
cp_hazard : coverpoint hazard_type  { bins raw = {RAW}; bins war = {WAR}; bins waw = {WAW}; bins none = {NONE}; }
cp_flush  : coverpoint flush_type   { bins branch_flush = {BRANCH}; bins exception = {EXCEPTION}; }
cp_stall  : coverpoint stall_type   { bins none = {NONE}; bins data_stall = {DATA}; }
cp_forward: coverpoint forward_type { bins none = {NONE}; bins ex_mem = {EX_MEM}; bins mem_wb = {MEM_WB}; }
X_hazard_stall: cross cp_hazard, cp_stall;

// ── NoC / 网络 ──
cp_routing   : coverpoint routing_type { bins xy = {XY}; bins odd_even = {ODD_EVEN}; bins adaptive = {ADAPTIVE}; }
cp_congestion: coverpoint congestion   { bins none = {NONE}; bins high = {HIGH}; bins saturated = {SATURATED}; }
cp_deadlock  : coverpoint deadlock_state { bins no_deadlock = {NONE}; bins resolved = {RESOLVED}; }
cp_qos       : coverpoint qos_level    { bins best_effort = {BE}; bins guaranteed = {GS}; }

// ── 加密 / 安全 ──
cp_mode       : coverpoint crypto_mode  { bins ecb = {ECB}; bins cbc = {CBC}; bins gcm = {GCM}; }
cp_key_len    : coverpoint key_len      { bins len128 = {128}; bins len256 = {256}; }
cp_side_channel: coverpoint sc_protection { bins timing_resistant = {TIMING}; bins none = {NONE}; }
cp_rng_quality: coverpoint rng_quality  { bins pass = {PASS}; bins fail = {FAIL}; }

// ── DMA ──
cp_desc     : coverpoint desc_type { bins single = {SINGLE}; bins chain = {CHAIN}; bins ring = {RING}; }

cp_dma_error: coverpoint dma_error { bins desc_error = {DESC_ERR}; bins addr_error = {ADDR_ERR}; bins timeout = {TIMEOUT}; }

// ── 中断控制器 ──
cp_int_prio: coverpoint int_prio { bins low = {LOW}; bins mid = {MID}; bins high = {HIGH}; }
```

## 四、元维度：覆盖模型自身也要被验证

**这一步几乎所有人都跳过，而它是「模型有没有洞」的唯一答案。**

| 自检项 | 手段 |
|---|---|
| 每个 bin 真的可命中吗 | 约束求解器查约束与 bin 是否一致；形式验证证明可达 |
| 每个 `ignore_bins` 真的不可达吗 | 形式验证证明不可达 **+** 覆盖率趋势图确认从未命中 |
| 覆盖模型有没有遗漏 | **mutation testing**：注入 bug → 跑测试 → 模型没捕获就是漏了 |
| 覆盖模型有没有冗余 | 查重复 bin、重叠 bin、无用 bin |
| 模型是否随设计更新 | 覆盖模型纳入版本控制，随覆盖率计划一起评审 |

`ignore_bins` 是**要拿证据换的**，不是「难覆盖就先 ignore」的垃圾桶 —— 这正是它和
「暂时的缺口」的分界线（门槛值见 `02_流程与签核/`）。

## 五、检查清单

| 检查项 | 问题 |
|---|---|
| 接口覆盖 | 所有输入输出信号的合法取值都覆盖了吗？ |
| 边界覆盖 | 最大值、最小值、临界值都覆盖了吗？ |
| 异常覆盖 | 非法命令、错误响应、超时都覆盖了吗？ |
| 结果覆盖 | 采样的是**激励+结果**，还是只有激励？ |
| 交叉覆盖 | 有意义的组合都交叉了吗？交叉是否爆炸？ |
| 时序覆盖 | 状态转移、握手序列、依赖序列都覆盖了吗？ |
| 并发覆盖 | 多事件同时发生都覆盖了吗？ |
| 系统覆盖 | 跨模块、端到端场景都覆盖了吗？ |
| 非功能覆盖 | 性能、功耗、时序、可靠性都覆盖了吗？ |
| 非法 bin | 架构上不可达的场景定义为 `illegal_bins` 了吗？ |
| 忽略 bin | 复位期间等无效周期定义为 `ignore_bins` 了吗？ |
| 需求追溯 | 每个 coverpoint 都能追溯到需求吗？ |
| 约束映射 | 每个 bin 都有对应的约束能命中它吗？ |
| 可命中性 | 每个 bin 都验证过可达吗？ |
| 不可达性 | 每个 `ignore` 都验证过不可达吗？ |
| 完整性 | 用 mutation testing 检验过覆盖模型吗？ |
| 冗余 | 检查过重复、重叠、无用 bin 吗？ |
| 版本 | 覆盖模型随设计变化更新了吗？ |

## 六、坑

| 坑 | 表现 | 修正 |
|---|---|---|
| 只覆盖正常路径 | 没有 error / slverr / decerr bin | 补异常维度（第 5 步） |
| 只采激励不采结果 | 分不清「发生了」和「被正确处理了」 | 联合采样激励与输出 |
| 交叉爆炸 | 全量 cross，bin 数上万，涨不上去也没人看 | 只交叉架构上有意义的组合 |
| 边界缺失 | 只有中间值，没有 max / min | 显式定义边界 bin |
| FSM 只列状态 | 没有转移弧 | 补 transition / 多周期 sequence bin |
| 队列只列水位 | 没有满时写 / 空时读 | 补边界交叉 |
| 忽略并发 | 没有多事件同时发生 | 补第 6 步 |
| 忽略系统 | 只做单模块 | 补第 7 步 |
| 忽略非功能 | 没有性能 / 功耗 / 时序 | 补第 8 步 |
| 忽略自检 | 没验证 bin 可达性 | 补第 9 步 |
| `ignore` 滥用 | 把难覆盖的直接 ignore | 豁免需证据 + 审批 |

**最值钱的两条**：交叉爆炸和 `ignore` 滥用 —— 前者让覆盖率数字失去意义，
后者让「100%」变成「我把它删掉了」。

## 七、出口：这个模型接下来去哪

本卡只到「列出一份可测量的覆盖点」。往下走：

| 下一步 | 在哪 |
|---|---|
| 覆盖点 → SystemVerilog covergroup 代码 | 工具链 `casemodel_tools`（见其 `readme.md` 的功能覆盖率方法学） |
| 缺口分析 → 补激励 → 再收 | `verify/07_度量与报告/覆盖率收敛/` |
| 目标值、waiver 门槛、签核标准 | `02_流程与签核/` |

**别忘了**：模型写出来只是起点。回归里永远 0% 的 bin，要么补激励，要么
拿可达性证据改成 `ignore_bins` —— **不能既不改模型也不给证据就签字**。
