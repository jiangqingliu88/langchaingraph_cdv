# DFT·CDC·安全设计

**位置**：`design/` 设计翼

> **三个「不写就出事、仿真还看不出来」的设计面**：可测性插入、跨时钟/复位域、
> 防篡改与侧信道。

## 边界

**不放**：CDC **怎么验**（断言怎么写、SpyGlass 报错怎么读）→
`verify/02_验证方法学/` 与 `verify/04_工具与脚本/SpyGlass/`；
DFT **覆盖率**怎么算 → `verify/07_度量与报告/`；安全**认证**要求 → `../../03_标准合规/`。

**本域只管「设计侧怎么做对」** —— 怎么证明做对了，在验证翼。

> **本域是跨翼话题的典型**：CDC 一个词，设计侧的处理和验证侧的检查是**两张卡**，
> 互相链接、不互相抄（见根 README 的 CDC 例子）。
