# 术语与索引

**位置**：共用域

> 全库的**检索骨架**：术语、缩写、总索引。其它域只写知识，不写索引。

| 文件 | 放什么 |
|---|---|
| [术语表.md](术语表.md) | 概念的中文名 / 英文名 / 一句话定义 / 在哪张卡展开 |
| [缩写表.md](缩写表.md) | 缩写 → 全称 → 中文 |
| [索引.csv](索引.csv) | **全库条目总表**（机器读）—— 每加一张卡必须补一行 |

## 边界

**不放**：具体知识 —— 这里只有「这个词什么意思」和「那条在哪」。

术语表与卡片的分工要抠清：术语表给**一句话定义**，展开在卡片里。
两边都写完整定义，就等于同一个定义有两份 —— 而两份一定会漂移。

## 为什么单独成一个域

因为它**被所有域引用**。放进任何一个知识域都会变成「谁都能改、谁都不负责」。
