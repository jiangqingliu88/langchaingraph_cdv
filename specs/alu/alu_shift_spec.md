## 1. 概述
执行 SLL/SRL/SRA 三种移位运算，32bit 数据通路。移位量由 B[4:0] 指定 (0-31)。

## 2. 功能需求

### 逻辑左移
**级别**：P0
**类型**：FUNCTIONAL
**描述**：SLL — 左移，低位补0，高位丢弃
**验收标准**：所有移位量 (0-31) 结果正确

### 逻辑右移
**级别**：P0
**类型**：FUNCTIONAL
**描述**：SRL — 右移，高位补0，低位丢弃
**验收标准**：所有移位量 (0-31) 结果正确

### 算术右移
**级别**：P1
**类型**：FUNCTIONAL
**描述**：SRA — 右移，高位按符号位填充
**验收标准**：正数/负数移位结果正确，覆盖率 ≥ 95%

### 移位溢出
**级别**：P2
**类型**：ERROR
**描述**：移位量超出范围 (≥32) 时的行为
**验收标准**：移位量 ≥ 32 时输出为 0 或符号扩展

## 3. 接口规范

| 信号 | 位宽 | 方向 | 协议 | 描述 |
|------|------|------|------|------|
| op_a[31:0] | 32 | INPUT | Native | 被移位数 |
| op_b[4:0] | 5 | INPUT | Native | 移位量 |
| op_sel[1:0] | 2 | INPUT | Native | SLL/SRL/SRA |
| result[31:0] | 32 | OUTPUT | Native | 移位结果 |

## 4. 时序约束

| 路径 | 约束 | 说明 |
|------|------|------|
| op_a/op_b → result | ≤ 1.5ns | 桶形移位器 |
