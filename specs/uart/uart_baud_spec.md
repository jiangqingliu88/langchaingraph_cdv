# UART 波特率发生器规格

## 功能描述
生成 16x 波特率时钟，支持 9600-115200 范围内所有标准波特率。

## 单元级需求 (UT)
- **REQ_UT_006**: 波特率分频计数器验证

## 计算公式
```
divisor = PCLK / (baud_rate × 16)
```

## 测试点
| 波特率 | 分频值 (PCLK=50MHz) | 误差 |
|--------|---------------------|------|
| 9600   | 326                 | 0.01% |
| 19200  | 163                 | 0.01% |
| 38400  | 81                  | 0.16% |
| 57600  | 54                  | 0.16% |
| 115200 | 27                  | 0.16% |
