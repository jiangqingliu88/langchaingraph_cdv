## 1. 概述
UART 接收模块负责将串行数据接收并转换为并行数据。支持 3x/8x/16x 过采样。

## 2. 功能需求

### 起始位检测
**级别**：P0
**类型**：FUNCTIONAL
**描述**：检测 RX 线的下降沿作为起始位
**验收标准**：无虚假起始位检测，抗毛刺

### 数据采样
**级别**：P0
**类型**：FUNCTIONAL
**描述**：在比特中点采样，3x/8x/16x 过采样可配置
**验收标准**：所有采样配置下数据正确

### 校验检测
**级别**：P0
**类型**：FUNCTIONAL
**描述**：N/E/O 校验位接收和验证
**验收标准**：校验错误检测正确，PE 标志置位

### 停止位检测
**级别**：P0
**类型**：FUNCTIONAL
**描述**：停止位接收验证，帧错误检测
**验收标准**：停止位错误时 FE 标志置位

### RX FIFO
**级别**：P1
**类型**：CONTROL
**描述**：接收 FIFO 管理和满标志
**验收标准**：FIFO 溢出时产生 overrun 标志

### 错误恢复
**级别**：P2
**类型**：ERROR
**描述**：帧错误/校验错误/溢出后的恢复
**验收标准**：错误后能正确接收下一帧

## 3. 接口规范

| 信号 | 位宽 | 方向 | 协议 | 描述 |
|------|------|------|------|------|
| clk | 1 | INPUT | — | 时钟 |
| rst_n | 1 | INPUT | — | 复位 |
| rx | 1 | INPUT | UART | 串行输入 |
| rx_data[7:0] | 8 | OUTPUT | — | 接收数据 |
| rx_valid | 1 | OUTPUT | — | 数据有效 |
| rx_error | 1 | OUTPUT | — | 帧/校验错误 |
| rx_overflow | 1 | OUTPUT | — | FIFO 溢出 |
| baud_tick | 1 | INPUT | — | 波特率时钟 |

## 4. 时序约束

| 路径 | 约束 | 说明 |
|------|------|------|
| rx → sample | ≥ 3x 过采样周期 | 抗干扰 |
| rx_valid → rx_data | ≤ 1 cycle | 数据有效 |

## 5. 功耗约束

| 模式 | 功耗 | 说明 |
|------|------|------|
| Active (接收中) | ≤ 3mW | 过采样工作 |
| Idle | ≤ 0.3mW | 等待起始位 |
