## 1. 概述
UART IP 集成 AXI4 总线接口，支持 9600-115200 波特率，5/6/7/8 数据位，N/E/O 校验，1/1.5/2 停止位。

## 2. 功能需求

### 数据发送
**级别**：P0
**类型**：FUNCTIONAL
**描述**：并行数据 → 串行输出，含起始位/数据位/校验位/停止位
**验收标准**：所有波特率和配置组合下发送正确

### 数据接收
**级别**：P0
**类型**：FUNCTIONAL
**描述**：串行输入 → 并行数据，3x/8x/16x 过采样
**验收标准**：所有波特率和配置组合下接收正确

### 波特率生成
**级别**：P0
**类型**：TIMING
**描述**：16x 波特率时钟生成，误差 ≤ 2%
**验收标准**：所有标准波特率误差在 ±2% 以内

### 校验与帧格式
**级别**：P0
**类型**：FUNCTIONAL
**描述**：N/E/O 校验生成与检查，帧格式配置
**验收标准**：校验错误检测正确，帧格式切换正确

### FIFO 缓冲管理
**级别**：P1
**类型**：CONTROL
**描述**：TX/RX FIFO 的读写指针和满空标志
**验收标准**：FIFO 不溢出/不下溢，满空标志正确

### DMA 集成
**级别**：P1
**类型**：CONTROL
**描述**：与 DMA 控制器的数据传输握手
**验收标准**：DMA 传输结束后中断正确触发

### 中断处理
**级别**：P1
**类型**：CONTROL
**描述**：TX empty/RX full/error 中断生成与清除
**验收标准**：所有中断源触发和清除正确

### 异常恢复
**级别**：P2
**类型**：ERROR
**描述**：帧错误/溢出/校验错误时的恢复行为
**验收标准**：错误后能恢复正常接收/发送

## 3. 接口规范

| 信号 | 位宽 | 方向 | 协议 | 描述 |
|------|------|------|------|------|
| clk | 1 | INPUT | — | 系统时钟 |
| rst_n | 1 | INPUT | — | 异步复位 |
| tx | 1 | OUTPUT | UART | 串行发送 |
| rx | 1 | INPUT | UART | 串行接收 |
| awaddr[31:0] | 32 | INPUT | AXI4 | 写地址 |
| wdata[31:0] | 32 | INPUT | AXI4 | 写数据 |
| rdata[31:0] | 32 | OUTPUT | AXI4 | 读数据 |
| irq_tx | 1 | OUTPUT | — | 发送中断 |
| irq_rx | 1 | OUTPUT | — | 接收中断 |
| irq_err | 1 | OUTPUT | — | 错误中断 |

## 4. 时序约束

| 路径 | 约束 | 说明 |
|------|------|------|
| rx → sample | ≥ 1/16 波特率周期 | 过采样 |
| tx 比特宽 | ±1% 波特率周期 | 发送精度 |
| AXI4 awready | ≤ 2 cycles | AXI 握手 |

## 5. 功耗约束

| 模式 | 功耗 | 说明 |
|------|------|------|
| Active (115200) | ≤ 5mW | 最高波特率 |
| Active (9600) | ≤ 2mW | 最低波特率 |
| Idle | ≤ 0.5mW | 无活动 |
| Sleep | ≤ 0.1mW | 时钟门控 |
