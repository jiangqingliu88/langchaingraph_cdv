================================================================================
                      Supported Data Widths
================================================================================

  ┌─────────┬────────────┬───────────────────────────────────────┐
  │  Width  │  Bytes/beat │  Usage Example                       │
  ├─────────┼────────────┼───────────────────────────────────────┤
  │   64b   │     8      │  Control registers, narrow bus       │
  │  128b   │    16      │  PCIe TLP, cache line (half)         │
  │  256b   │    32      │  DMA, NoC flit                       │
  │  512b   │    64      │  HBM, wide memory interface          │
  └─────────┴────────────┴───────────────────────────────────────┘

  Each width uses its own registry specialization:
    rtl_sc_registry #(64)
    rtl_sc_registry #(128)
    rtl_sc_registry #(256)
    rtl_sc_registry #(512)

                      Registration Summary

  ┌─────────────────────────────────────────────────────────────────────────┐
  │  SV Side (in UVM test)                                                  │
  │                                                                         │
  │  reg_t::init(this, cfg);                    // once                     │
  │  reg_t::register_rtl("dma_0", mon.ap);      // one line per RTL ch      │
  │  reg_t::register_sc("dma_0");               // one line per SC ch       │
  │  reg_t::register_cfg("dma_cfg");            // one line per cfg ch      │
  │  reg_t::connect_all();                      // once in connect_phase    │

  └─────────────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────────────┐

  │                                                                         │

  │  sc_registry::reg_cfg("dma_cfg", module.cfg_sock);  // cfg socket       │
  │  sc_registry::connect_all();                        // once             │
  └─────────────────────────────────────────────────────────────────────────┘


================================================================================
                      File Structure
================================================================================

  rtl_sc/
  ├── src/                        SV core (compiled as package)
  │   ├── rtl_sc_pkg.sv           Package entry point
  │   ├── rtl_sc_cfg.sv           Platform config (timeout, max_errors)
  │   ├── rtl_sc_txn.sv           Internal transaction (parameterized DW)
  │   ├── rtl_sc_channel.sv       Comparison engine (queue + watchdog)
  │   ├── rtl_sc_monitor_base.sv  RTL monitor base class
  │   ├── sc_receiver.sv          TLM2.0 target (receives SC data via UVMC)
  │   ├── cfg_sender.sv           Config sender (sends struct bytes to SC)
  │   └── rtl_sc_registry.sv      Unified SV registration API
  │
  ├── sc/                         SC side
  │   └── sc_registry.h           Unified SC registration API
  │
  └── example/                    Test examples
      ├── rtl_data_if.sv          RTL signal interface
      ├── rtl_monitor_ex.sv       RTL monitor example
      ├── tb_top.sv               Single-channel testbench
      ├── tb_multi_channel.sv     Multi-width testbench (64/128/256/512)
      ├── tb_multi_socket.sv      Multi-socket + struct config testbench
      ├── sc_model.cpp            SC single-channel model
      ├── sc_model_multi.cpp      SC multi-width model
      └── sc_model_multi_socket.cpp  SC multi-socket + struct config model
