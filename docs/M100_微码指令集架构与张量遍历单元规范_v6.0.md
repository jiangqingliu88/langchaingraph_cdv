## 1. 架构核心基石：TWU 的引入

### 1.1 设计哲学

在 TPB（Tensor Processing Block，张量处理块）中，**功能单元（FC：TCU、CVU、DTDU、GSDU）本身不具备地址生成能力**。
它们的数据读写完全依赖内部 **TWU（Tensor Walking Unit，张量遍历单元）** 生成复杂的非线性、嵌套循环地址序列。

> **一句话**：TWU 把"地址计算"从软件/指令流中剥离，变成纯硬件状态机的走步逻辑。

### 1.2 TWU 的职责与配备

- **配备规则**：每个功能单元通常包含 **2 个或更多输入 TWU** + **1 个输出 TWU**。
- **地址生成**：多层嵌套循环状态机，由 `Initial`、`Step`、`Final` 控制访问路径；
  最终物理地址 = 各层当前计数之和（含基址偏移 + 双缓冲偏移）。
- **双缓冲**：通过 `Buffer_Offset` 无缝交替，复用地址总线空闲周期，无需专用数据通路。

```
                    ┌─────────────────────────────────────────┐
                    │                TPB                       │
                    │  ┌─────────────┐  ┌──────────────────┐  │
   DRBN / HBSM ◄───►│  │  TWU-Input0 │  │                  │  │
   (数据流)         │  │  TWU-Input1 │──►│  功能单元(FC)     │  │
                    │  │  TWU-InputN │  │  TCU/CVU/DTDU/   │  │
                    │  └─────────────┘  │  GSDU             │  │
                    │                   │                  │  │
                    │  ┌─────────────┐  └──────────────────┘  │
                    │  │  TWU-Output │◄── 计算结果写回        │
                    │  └─────────────┘                        │
                    └─────────────────────────────────────────┘
```

## 2. 微码包物理结构（字节级 TLV）

### 2.1 微码包物理流格式（CIQ → TPB 引擎）

| 流分段 | 字段名 | 大小 | 物理解析动作 |
|--------|--------|------|--------------|
| 流前部 | `OPCODE` | 4 Byte | 底层驱动类型（0=DTDU, 1=CVU, 2=TCU, 3=GSDU, 4=CSU） |
| 流前部 | `PACKET_LEN` | 4 Byte | 微码负载总长度（含头部） |
| 流前部 | `TTU_SYNC_HEADER` | 32 Byte | 同步与迭代控制头，SU 截获解析 |
| 流中部 | `TWU_CONFIG_BLOCK` | 变长（核心） | 所有 TWU 的嵌套循环参数 |
| 流后部 | `FUNCTION_CFG` | 变长 | 具体算子配置 |

```
┌──────────┬──────────┬──────────────────┬───────────────────┬───────────────────┐
│  OPCODE  │PKT_LEN   │  TTU_SYNC_HEADER │  TWU_CONFIG_BLOCK │  FUNCTION_CFG     │
│  4 B     │  4 B     │  32 B            │  变长 (TLV 流)     │  变长              │
└──────────┴──────────┴──────────────────┴───────────────────┴───────────────────┘
```

### 2.2 TTU_SYNC_HEADER（32 Byte 字段布局）

| 偏移 | 字段 | 位宽 | 语义 |
|------|------|------|------|
| 0 | `sv_depend_id` | 8 bit | 等待的信号量 ID（0=无需等待） |
| 8 | `sv_release_id` | 8 bit | 完成后释放的信号量 ID（0=不释放） |
| 16 | `loop_max` | 16 bit | 包级迭代次数（0=由 TWU 驱动） |
| 32 | `loop_stride` | 16 bit | 包级迭代地址步长 |
| 48 | `loop_exit_act` | 4 bit | 完成后动作（0=无, 1=CSU 中断, 2=释放 SV, 3=两者） |
| 52 | `flags` | 12 bit | 保留/调试 |
| 64 | `reserved` | 192 bit | 保留（对齐 256 bit） |

### 2.3 TWU_CONFIG_BLOCK 的 TLV 流（v6.0 字节级）

每个 TLV 三元组：

```
┌──────────┬──────────┬──────────────────────────────┐
│ TYPE (1B)│ LEN (2B) │ VALUE (变长)                  │
└──────────┴──────────┴──────────────────────────────┘
```

**TLV 类型表（v6.0 完整版）**：

| TYPE | 名称 | VALUE 长度 | 说明 |
|------|------|-----------|------|
| `0x01` | `TWU_LEVEL_CONFIG` | 12 B | Init(4B) Step(4B) Final(4B) |
| `0x02` | `TWU_BLOCK_START` | 2 B | 角色 ID（0=in0, 1=in1, 2=out）+ 层级数 |
| `0x03` | `TWU_BLOCK_END` | 0 B | |
| `0x04` | `BUFFER_OFFSET` | 4 B | 双缓冲偏移 |
| `0x05` | `TWU_BASE_ADDR` | 4 B | TWU 基址 |
| `0x06` | `TWU_PRECISION` | 1 B | 数据精度 |
| `0x0F` | `END_OF_BLOCK` | 0 B | TWU_CONFIG_BLOCK 结束 |

**字节级示例**（一个 2 层输入 TWU + 双缓冲）：

```
# TWU_BLOCK_START (in0, 2 levels)
0x02 0x0002  0x00 0x02
# Level 0: Init=0 Step=1 Final=16
0x01 0x000C  0x00000000 0x00000001 0x00000010
# Level 1: Init=0 Step=16 Final=64
0x01 0x000C  0x00000000 0x00000010 0x00000040
# Buffer_Offset = 1024
0x04 0x0004  0x00000400
# TWU_BLOCK_END
0x03 0x0000
# END_OF_BLOCK
0x0F 0x0000
```

## 3. TWU_CONFIG 结构与硬件状态机

### 3.1 结构体

```
[ TWU_Level_N ]
  Init:     <起始地址偏移>
  Step:     <每次递增步长>
  Final:    <达到此值触发上层递增>    # 自身重置为 Init
  [可选] Buffer_Offset: <双缓冲偏移>  # 仅最外层
```

### 3.2 硬件执行逻辑（形式化）

```
输入:  levels[0..L-1] = {Init, Step, Final}   (levels[0] = 最内层)
       base_addr, buf_offset, buf_sel

初始化:
  for l in 0..L-1:  cnt[l] = levels[l].Init
  buf_sel = 0

每周期迭代 (功能单元请求一个地址):
  addr = base_addr + buf_sel * buf_offset
  for l in 0..L-1:  addr += cnt[l]
  输出 addr

  触顶判定 (从最内层向外):
  cnt[0] += levels[0].Step
  for l in 0..L-1:
    if cnt[l] >= levels[l].Final:
      cnt[l] = levels[l].Init          # 重置/回滚
      if l+1 < L:
        cnt[l+1] += levels[l+1].Step   # 外层递增
      else:
        完成 (所有层触顶)               # SU 检测 → loop_exit_act

  双缓冲切换 (可选):
  if 最外层触顶 and buf_offset > 0:
    buf_sel ^= 1
```

**关键规则**：
1. 最内层无条件递增（Step）。
2. 触顶 → 外层递增，自身回滚到 Init。
3. 物理地址 = 所有层计数之和（+ 基址 + 缓冲偏移）。

### 3.3 状态迁移

```
                ┌──────────┐
                │  IDLE    │◄──────────────┐
                └────┬─────┘               │
          收到配置包 │                      │
                ┌────▼─────┐               │
                │ CONFIG   │               │
                └────┬─────┘               │
          等待 SV 置位│                     │
                ┌────▼─────┐               │
                │ WALKING  │──最内层递增──►│
                │ (走步)    │               │
                └────┬─────┘               │
      所有层触顶      │                     │
                ┌────▼─────┐               │
                │ DONE     │──loop_exit_act│
                └──────────┘               │
                   │ 双缓冲: buf_sel ^= 1  │
                   └──────────────────────┘
```

## 4. 双缓冲硬件切换协议

### 4.1 机制

- TWU 最外层指定 `Buffer_Offset`；当外部控制器向 HBSM 输入数据块时，TWU 无缝切换基址。

### 4.2 寄存器级握手

| 信号 | 方向 | 语义 |
|------|------|------|
| `twu_buf_sel` | TWU → FC | 当前活动缓冲区（0=A, 1=B） |
| `twu_buf_switch_req` | FC → TWU | 请求切换 |
| `twu_buf_switch_ack` | TWU → FC | 切换完成 |
| `hbsm_buf_full[1:0]` | DTDU → TWU | 缓冲区数据就绪 |

### 4.3 流水线时间线

```
  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐
  │ TCU 计算 缓冲区A │  │ TCU 计算 缓冲区B │  │ TCU 计算 缓冲区A │
  └──────────────┘  └──────────────┘  └──────────────┘
            └─ DTDU 搬入 缓冲区B ─┘  └─ DTDU 搬入 缓冲区A ─┘
```

## 5. 完整指令助记符表（v6.0 新增）

> 每条配置指令 = **助记符 + 操作数**，汇编器展开为 4 段微码包（头部 + TWU + FC）。

### 5.1 指令总表

| 助记符 | 编码 | 引擎 | 操作数（汇编视角） | 说明 |
|--------|------|------|--------------------|------|
| `DTDU.LOAD` | `0x00` | DTDU | `src, dst, twu_in, twu_out, elem, xform` | 从 DRBN 刮取数据到 HBSM |
| `DTDU.STORE` | `0x01` | DTDU | `src, dst, twu_in, twu_out, elem` | HBSM → DRBN |
| `DTDU.TRANSFORM` | `0x02` | DTDU | `src, dst, twu_in, twu_out, xform` | 搬运 + 变换（转置/切片/填充） |
| `CVU.VADD` | `0x10` | CVU | `va, vb, vc, vec_len, lane` | 向量加 |
| `CVU.VMUL` | `0x11` | CVU | `va, vb, vc, vec_len, lane` | 向量乘 |
| `CVU.VRELU` | `0x12` | CVU | `va, vc, vec_len, lane` | ReLU |
| `CVU.VMM` | `0x13` | CVU | `va, vb, vc, vec_len` | 向量矩阵乘（小 GEMM 降级） |
| `TCU.MATMUL` | `0x20` | TCU | `A, B, C, M, K, N, dtype` | 矩阵乘 |
| `TCU.CONV2D` | `0x21` | TCU | `A, W, C, M, K, N, kh, kw, sh, sw, ph, pw` | 二维卷积 |
| `TCU.CONV3D` | `0x22` | TCU | `A, W, C, ...(三维)` | 三维卷积 |
| `TCU.POOL` | `0x23` | TCU | `A, C, kh, kw, sh, sw, mode` | 池化 |
| `GSDU.GATHER` | `0x30` | GSDU | `src, dst, idx, twu_out` | 按索引表聚集 |
| `GSDU.SCATTER` | `0x31` | GSDU | `src, dst, idx, twu_out` | 按索引表散射 |
| `GSDU.XMIT` | `0x32` | GSDU | `src, dst, twu_out` | 数据转发（跨 TPB） |
| `GSDU.CUSTOM` | `0x33` | GSDU | `src, dst, func_id` | 自定义加速（crypto/校验） |
| `CSU.LAUNCH` | `0x40` | CSU | `cpu_id, entry` | 启动 RISC-V 核 |
| `CSU.WAIT` | `0x41` | CSU | `sv_id, timeout` | 等待信号量 |
| `CSU.INT` | `0x42` | CSU | `cpu_id, int_vec` | 发中断 |
| `CSU.SYNC` | `0x43` | CSU | `sv_id, count` | 多核同步（barrier） |

### 5.2 编码规则（v6.0）

- **高 4 bit** = 引擎类（`0x0`=DTDU, `0x1`=CVU, `0x2`=TCU, `0x3`=GSDU, `0x4`=CSU）。
- **低 4 bit** = 引擎内操作码。
- 与 v4.0 的 `OPCODE` 字段（0-4）**兼容**：`OPCODE = 编码 >> 4`。

## 6. DTDU 类：数据搬运与变换（OPCODE = 0）

### 6.1 FUNCTION_CFG 字段

| 字段 | 位宽 | 语义 |
|------|------|------|
| `dtdu_op` | 4 bit | 0=LOAD, 1=STORE, 2=TRANSFORM |
| `src_base` | 32 bit | 源基址（DRBN） |
| `dst_base` | 32 bit | 目标基址（HBSM） |
| `elem_width` | 4 bit | 0=8b, 1=16b, 2=32b, 3=bf16, 4=fp32 |
| `transform` | 8 bit | 0=直通, 1=转置, 2=切片, 3=填充, 4=dequant |

### 6.2 示例：非连续行刮取

```
DTDU.LOAD  src=DRBN[0x1000]  dst=HBSM[0x2000]  elem=bf16
  TTU_SYNC_HEADER: sv_depend_id=3, loop_exit_act=2
  Input_TWU (刮取非连续行):
    L0: Init=0  Step=1  Final=128
    L1: Init=0  Step=4096 Final=32    # stride=4096
  Output_TWU (紧凑写入):
    L0: Init=0  Step=1  Final=128
    L1: Init=0  Step=128 Final=32
```

## 8. TCU 类：张量/矩阵计算（OPCODE = 2）

### 8.1 FUNCTION_CFG

| 字段 | 位宽 | 语义 |
|------|------|------|
| `tcu_op` | 4 bit | 0=MATMUL, 1=CONV2D, 2=CONV3D, 3=POOL |
| `M` / `K` / `N` | 16+16+16 bit | 矩阵维度 |
| `kernel_h/w` | 8+8 bit | 卷积核 |
| `stride_h/w` | 4+4 bit | 步长 |
| `pad_h/w` | 4+4 bit | 填充 |
| `dtype` | 4 bit | 0=int8, 1=int16, 2=bf16, 3=fp16, 4=fp32 |

### 8.2 GEMM 示例（M×K · K×N → M×N）

```
TCU.MATMUL  A=HBSM[0x3000]  B=HBSM[0x4000]  C=HBSM[0x5000]  M=64 K=64 N=64
  Input_TWU_A:
    L0: Init=0 Step=1  Final=64    # K 维连续
    L1: Init=0 Step=64 Final=64    # M 维
  Input_TWU_B:
    L0: Init=0 Step=1  Final=64    # N 维连续
    L1: Init=0 Step=64 Final=64    # K 维
  Output_TWU_C:
    L0: Init=0 Step=1  Final=64    # N 维
    L1: Init=0 Step=64 Final=64    # M 维
```

### 8.3 CONV2D 滑窗 TWU 配置（卷积魔法）

```
TCU.CONV2D  M=H*W  K=C*kh*kw  N=Co  kernel=3x3  stride=1  pad=1
  Input_TWU_A (滑窗展开):
    L0: Init=0 Step=1    Final=3      # kw
    L1: Init=0 Step=W    Final=3      # kh
    L2: Init=0 Step=1    Final=Cin    # 通道
    L3: Init=0 Step=W*Cin Final=H*W   # 空间位置
  Input_TWU_B (权重):
    L0: Init=0 Step=1 Final=3
    L1: Init=0 Step=3 Final=3
    L2: Init=0 Step=9 Final=Cin
    L3: Init=0 Step=Cin*9 Final=Co
  Output_TWU_C:
    L0: Init=0 Step=1 Final=Co
    L1: Init=0 Step=Co Final=H'*W'
    Buffer_Offset: H'*W'*Co          # 双缓冲输出
```

## 10. CSU 类：CPU 启动与中断（OPCODE = 4）

### 10.1 说明

- CSU **不涉及数据访问**，指令**不带 TWU_CONFIG_BLOCK**。
- 接收 RISC-V 扩展指令，循环结束后通过**紫线**发硬件中断。

### 10.2 FUNCTION_CFG

| 字段 | 位宽 | 语义 |
|------|------|------|
| `csu_op` | 4 bit | 0=LAUNCH, 1=WAIT, 2=INT, 3=SYNC |
| `cpu_id` | 8 bit | 目标核 ID |
| `int_vec` | 16 bit | 中断向量号 |
| `sv_signal` | 8 bit | 关联信号量 |

## 11. 内存模型：HBSM / DRBN 统一编址（v6.0 新增）

### 11.1 地址空间划分

```
0x0000_0000 ┌────────────────┐
            │   HBSM          │  TPB 内高带宽共享内存 (片内 SRAM)
            │   (可被所有 FC  │
            │    经 TWU 访问) │
0x0FFF_FFFF ├────────────────┤
            │   (保留/映射)   │
0x1000_0000 ├────────────────┤
            │   DRBN          │  片外 DRAM 块网络 (经 DTDU 刮取)
            │   (仅 DTDU      │
            │    可直接访问)  │
0xFFFF_FFFF └────────────────┘
```

### 11.2 访问规则

| 引擎 | HBSM 直接访问 | DRBN 直接访问 | 说明 |
|------|:---:|:---:|------|
| TCU / CVU | ✅ | ❌ | 只能经 TWU 读 HBSM |
| GSDU | ✅ | ✅ | 输出 TWU 可任意映射 |
| DTDU | ✅ | ✅ | 唯一可读写 DRBN 的引擎 |
| CSU | ❌ | ❌ | 无数据访问 |

### 11.3 地址宽度

- 物理地址：**32 bit**（HBSM 与 DRBN 统一编址，高 bit 区分域）。
- TWU 各层计数宽度：**16 bit**（单层最大 64K 元素），支持 8 层嵌套。
- 最终地址：`base(32b) + Σ cnt[l](16b×8) + buf_sel×buf_offset(32b)`，硬件 34 bit 内部累加。

## 12. 同步信号量 SV 形式化语义（v6.0 新增）

### 12.1 SV 集合

每个 TPB 拥有 **64 个信号量 `SV[0..63]`**，初始为 0。

### 12.2 操作原语

```
P(sv_id, timeout):
  loop:
    if SV[sv_id] > 0: SV[sv_id]--; return OK
    if timeout 超时:  return TIMEOUT (触发 SU_ERR_SV_TIMEOUT)
    等待 (时钟节拍轮询或事件驱动)

V(sv_id):
  SV[sv_id]++

BROADCAST(sv_id, count):
  SV[sv_id] += count     # 多核/多 TPB 同步用
```

### 12.3 与微码包的绑定

| 场景 | 使用 |
|------|------|
| 等待 DMA 完成 | `sv_depend_id = <DMA 完成时 V 的 SV>` |
| 通知下游 TPB | `sv_release_id = <下游等待的 SV>` |
| 双缓冲切换节拍 | DTDU 每搬完一块 `V(sv)`，TWU 的 `hbsm_buf_full` 联动 |
| 多核 barrier | `CSU.SYNC sv_id count` → BROADCAST |

### 12.4 形式化：SU 状态机

```
SU 截获 TTU_SYNC_HEADER:
  if sv_depend_id != 0:
    P(sv_depend_id)                      # 挂起流水线
  ... TWU 执行 ...
  if 所有 TWU 完成:
    if loop_exit_act & RELEASE_SV:
      V(sv_release_id)
    if loop_exit_act & CSU_INT:
      CSU.INT(cpu_id, int_vec)
    if loop_max > 0:
      更新包级基址 (loop_stride), 重新触发 TWU
```

## 13. TPB MMIO 寄存器接口（v6.0 新增）

### 13.1 寄存器视图（RISC-V 核经 CSR/MMIO 访问）

| 偏移 | 寄存器 | 宽度 | 语义 |
|------|--------|------|------|
| `0x00` | `TPB_STATUS` | 32b | busy/error/pipe_depth |
| `0x04` | `TPB_CTRL` | 32b | start/reset/int_enable |
| `0x08` | `CIQ_WR_PTR` | 32b | CIQ 写指针（软件填包） |
| `0x0C` | `CIQ_RD_PTR` | 32b | CIQ 读指针（硬件消费） |
| `0x10` | `CIQ_BASE` | 32b | 微码包队列基址 |
| `0x14` | `CIQ_LEN` | 32b | 队列长度 |
| `0x20` | `SV_SET[0..63]` | 64×32b | 信号量软件置位（调试/旁路） |
| `0x80` | `TWU_DBG_CNT[0..7]` | 8×32b | TWU 各层当前计数（调试） |
| `0xA0` | `TWU_DBG_ADDR` | 32b | 最后生成地址（调试） |
| `0xC0` | `INT_STATUS` | 32b | 中断状态 |
| `0xC4` | `INT_MASK` | 32b | 中断屏蔽 |
| `0xC8` | `ERR_STATUS` | 32b | 错误状态 |

### 13.2 软件下发流程

```
1. 软件构造微码包（汇编器/编译器生成字节流）
2. 写 CIQ_BASE/CIQ_LEN 配置队列
3. 写 CIQ_WR_PTR 推进写指针
4. 写 TPB_CTRL.start = 1
5. CIQ 硬件消费包 → 分发给目标引擎
6. 中断/轮询 TPB_STATUS 判断完成
```

## 14. 汇编/编译工具链与算子→微码生成（v6.0 新增）

### 14.1 汇编器视图

```
# 伪指令示例（汇编器展开为 4 段微码包）
TCU.CONV2D  A[0x3000], W[0x4000], C[0x5000],
            M=1024, K=432, N=64, kernel=3x3,
            stride=1, pad=1, dtype=bf16,
            sv_depend=5, sv_release=6, exit_int=1
```

汇编器输出：
1. 头部：`OPCODE=2, PACKET_LEN=<计算>, TTU_SYNC_HEADER{sv=5,rel=6,exit=1}`
2. TWU_CONFIG_BLOCK：从 A/W/C 的形状自动推导嵌套循环（§8.3 规则）
3. FUNCTION_CFG：`tcu_op=1, M=1024, K=432, N=64, kh=3, kw=3, sh=1, sw=1, ph=1, pw=1, dtype=2`

### 14.2 算子→TWU 自动推导规则（编译器侧）

| 算子 | TWU 推导 |
|------|----------|
| GEMM (M,K,N) | inA: [K内层, M外层]; inB: [N内层, K外层]; outC: [N内层, M外层] |
| CONV2D (H,W,Cin,Co,kh,kw) | inA: [kw, kh, Cin, H*W 空间]; inB: [kw, kh, Cin, Co]; outC: [Co, H'*W'] |
| 转置 (M,N) | inA: [N内层, M外层]; out: [M内层, N外层]（Step 互换） |
| 切片 | 对应层 Init/Step 设置偏移与步长 |
| 双缓冲 | 最外层加 Buffer_Offset = 单块大小 |

### 14.3 工具链流水线

```
算子图 (ONNX/TorchScript)
  → 编译器 (算子分解 + 内存规划)
  → 指令选择器 (映射到 5 大引擎)
  → TWU 推导器 (形状 → 嵌套循环)
  → 汇编器 (TLV 编码)
  → 微码包二进制
  → CIQ 队列
```

## 15. 完整业务闭环：双缓冲流水线卷积算子

### 15.1 CIQ 下发微码包

```
[ 流前部 ]
OPCODE = 2 (TCU)
PACKET_LEN = <总长度>

[ 流前部 ]
TTU_SYNC_HEADER
  sv_depend_id: 5
  sv_release_id: 6
  loop_max: 0
  loop_exit_act: 1        # CSU 中断

[ 流中部 ]
TWU_CONFIG_BLOCK
  Input_TWU_0 (特征图, 3层+双缓冲)
  Input_TWU_1 (权重)
  Output_TWU  (结果, 双缓冲)

[ 流后部 ]
FUNCTION_CFG (TCU_CONV2D)
  M=1024  K=432  N=64  kernel=3x3  stride=1  pad=1  dtype=bf16
```

### 15.2 物理运行轨迹

1. CSU 接收并解析头部，SU 挂起等 `SV_5`。
2. DMA 搬完第一块到 HBSM 缓冲区 A，点亮 `SV_5`。
3. SU 放行，TWU 生成地址。
4. TCU 从缓冲区 A 计算第一块卷积。
5. 外层循环边界：TWU 自动切换基址到 `Buffer_Offset`（缓冲区 B）。
6. 切换瞬间 DTDU 利用总线空闲把下一批搬到缓冲区 A。
7. TWU 遍历完，SU 检测所有层 Final 满足。
8. CSU 发硬件中断通知 RISC-V 核。

### 15.3 时序图

```
Clk  │ SV_5 │  TWU走步(A)  │ TCU计算(A) │ buf切换 │ TWU走步(B) │ TCU计算(B) │ INT
─────┼──────┼─────────────┼────────────┼─────────┼────────────┼────────────┼────
     │  _/‾ │             │            │         │            │            │
     │      │ ████████████ │  ████████  │         │            │            │
     │      │             │            │  buf↑  │ ████████████ │  ████████  │
     │      │             │            │         │            │            │  _/‾
     │      │  (DTDU 搬入 B)          │  (DTDU 搬入 A)         │            │
```

## 16. 中断、错误与调试

### 16.1 中断路径

- **紫线**：TPB → 外部 RISC-V 核专用中断线。
- 触发：`loop_exit_act` 含 `CSU_INT`，且 TWU 所有层触顶。

### 16.2 错误码

| 错误码 | 含义 | 恢复 |
|--------|------|------|
| `TWU_ERR_OVF` | 计数器溢出 | 冻结，发中断，丢弃包 |
| `TWU_ERR_ADDR` | 地址越界 | 冻结，发中断 |
| `SU_ERR_SV_TIMEOUT` | 信号量超时 | 重试或上报 |
| `FC_ERR_CFG` | 配置非法 | 解析阶段报错，不启动 |

### 16.3 调试

- 影子寄存器：`twu_cnt[l]`、`twu_buf_sel`、`twu_last_addr`。
- 单步走步模式 + 地址轨迹回放（trace 端口导出）。
